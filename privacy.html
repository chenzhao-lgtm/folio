Folio 隐私政策

更新及生效日期：2026-10-23

本政策适用于 Folio iOS App、Folio 网页版，以及本隐私政策和技术支持等公开网页，说明它们会处理哪些信息、怎么处理、保存多久，以及你可以怎样管理这些信息。

一、简要说明

  • Folio 不需要注册或登录，没有账号。
  • App 没有自己的服务器，不会把你的收藏、设置、反馈记录或使用情况上传给我们。
  • 收藏、设置和消息记录保存在你自己的设备上（也可能包含在你的设备备份里，见第十一节）。删除 App（网页版为清除网站数据）即可从设备上清除。
  • App 不含广告，不含统计分析或追踪工具，不出售你的个人信息，也不对你做用户画像。
  • iOS App 的界面、字体和内容都打包在 App 里，只在下面列出的情况下连接网络。网页版的文件都来自 Folio 网站本身（托管在 GitHub Pages 上，见第六节），不从 Google 等其他网站加载字体或脚本。
  • 内容更新：App 在启动、回到前台和检查更新时，会从阿里云对象存储（OSS）下载最新的资源数据（一个公开文件，见第八节），新收录的资源不用更新 App 就能看到。这个请求不发送你的任何个人信息。
  • 除 Apple 提供给开发者的数据（见第六节）外，只有当你主动给我们发邮件时，我们才会收到你的信息。

二、我们是谁

Folio 由一位个人开发者开发和运营，即 App Store 上 Folio 产品页标明的开发者。本政策中的「我们」指 Folio 的开发者。

联系邮箱：1421718903@qq.com。在 App 内，也可以在 我的 → 帮助与支持 → 联系我们 中找到。

三、保存在设备上的信息

为了记住你的选择，App 会在你的设备上保存以下信息。iOS App 把它们保存在 App 自己的存储空间里；网页版把它们保存在浏览器为该网站域名提供的本地存储（localStorage）里。App 不会把这些信息自动发送给我们或任何第三方（设备备份见第十一节）。

  • 设置和收藏：当前选择的行业、排序方式、视图密度、语言、触感反馈的开关，以及你收藏的资源列表。在你收藏、取消收藏或修改这些设置时保存。
  • 外观：你选择的浅色或深色模式；选择「跟随系统」时不保存。
  • 使用引导：是否已经看过首次使用引导（看完或跳过后记一下，以后不再自动弹出）。
  • 消息中心：内容更新提醒、每日精选（当天推荐的资源编号和当时选中的行业）、消息和系统通知的已读状态，以及用来判断是否有新收录资源的数据版本号和资源编号。每条消息都会记录生成时间，因此每日精选也记下了你在每个用过 App 的日子里第一次打开或切回 App 的时间（只保留最近 7 条，即最近 7 个用过 App 的日子）。
  • 反馈记录：每次提交「举报 / 纠错」，App 都会在消息中心保存一份完整的反馈内容（见第四节），包括你写的说明和填写的联系方式，方便你之后再次复制。这些记录会长期保留，见第十一节。
  • 内容数据：最近一次下载的资源数据（见第八节），没联网时继续使用。它是公开文件的副本，不包含你的任何信息。

搜索词和还没提交的反馈表单内容只在使用时临时保留，不会被保存。App 不使用 Cookie，也不会生成或保存任何用来识别你或你设备的标识符。

App 还会读取系统的语言、深浅色和「减弱动态效果」设置，用来调整界面。App 不会保存或发送这些设置。

此外，使用网页版时，浏览器可能会缓存网页文件。这些缓存由浏览器管理，不包含你的个人信息。

四、举报、纠错和联系我们

你可以通过 我的 → 帮助与支持 → 举报 / 纠错，或资源详情页里的「这条信息有误？纠错 / 举报」，告诉我们资源下线、信息有误、侵权等问题，也可以提出建议。

提交时，App 会生成一段反馈内容，包括：反馈类型；你选中的资源的名称和编号，或你填写的资源名称；你写的具体说明；你选填的联系方式；数据版本；提交时设备上的日期和时间。

App 本身不会把这段内容发送出去。表单下方会说明采用哪种方式：一种是把内容复制到剪贴板，由你自己粘贴到邮件里发到 1421718903@qq.com；另一种是在你设备上的邮件 App 里打开一封填好内容的邮件，发不发由你决定。

在 App 的「联系我们」页面，你可以点「复制邮箱」复制我们的邮箱地址，或点「写邮件」打开你的邮件 App。用「写邮件」打开的邮件会预先填好 App 版本、数据版本、系统类型（例如 iOS）和界面语言，方便我们排查问题；这些信息不包含你的个人信息，你可以在发送前删改。你也可以点「问题排查信息」只复制这几项。

如果你给我们发了邮件，我们会收到邮件内容和你附上的截图、录屏等附件，以及你的邮箱地址、发件人名称，和邮件 App 或邮件服务自动附带的信息（例如发送时间、邮件签名；部分邮件服务还会在邮件头中附带发件 IP 地址）。

我们只用这些信息处理你反馈的问题（包括更正或移除相关条目、处理侵权投诉）、参考你的建议改进 Folio，以及回复你，不会用于其他目的。

处理侵权投诉时，我们可能会请你提供权利或授权证明，其中可能包含你的姓名、单位或身份信息。我们只用它核实投诉，保存期限见第十一节。除非确有必要，请不要发送身份证件号码等敏感个人信息。Folio App 本身不会要求你提供敏感个人信息。

联系方式是选填的，请只填写处理问题所需要的信息。填写时，iOS 或浏览器可能会建议填入你自己的邮箱地址，只有你点选后才会填入。

五、分享和剪贴板

你点「分享」时，App 会打开系统分享面板。分享的内容只有资源名称、本站写的导语和来源名称，不包含你的个人信息，发给谁由你决定。如果设备不支持系统分享，这段内容会被复制到剪贴板。

App 只在你点按相应按钮（分享、提交反馈、再次复制、复制邮箱、问题排查信息）时写入剪贴板，从不读取剪贴板。

请注意：剪贴板里的内容可以被其他 App 读取（App 自行读取时，iOS 通常会先询问你）；如果你开启了「接力」，通用剪贴板还可能让它出现在你同一 Apple 账户下的其他设备上。反馈内容里如果有你的联系方式，也会一起被复制。

六、第三方服务

iOS App 使用开源框架 Capacitor 把网页内容打包成 App，它只在你的设备上运行，不收集也不向外发送数据。除此之外，App 没有接入其他第三方 SDK，也没有任何统计分析、广告、推送、登录或崩溃上报类 SDK。界面使用的开源字体 Geist 和 JetBrains Mono 也打包在 App 和网页版里，不从 Google Fonts 等字体服务加载。

我们不会出售或出租你的个人信息。以下服务会在特定情况下收到一些信息，并按各自的隐私政策处理：

GitHub Pages（GitHub）：Folio 网页版、本隐私政策和技术支持页面托管在 GitHub Pages 上。你访问这些网页时，GitHub 会收到并可能记录标准的访问信息，例如 IP 地址、浏览器类型、来源网址和访问的页面。

GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

阿里云对象存储 OSS（阿里云）：App 和网页版的资源数据文件存放在阿里云 OSS 上，服务器位于中国香港。App 和网页版下载它时，阿里云会收到并可能记录标准的访问信息，例如 IP 地址、设备和浏览器类型、访问时间和请求的文件。

阿里云隐私权政策：https://terms.aliyun.com/legal-agreement/terms/suit_bu1_ali_cloud/suit_bu1_ali_cloud201902141711_54837.html

Apple：Folio iOS App 通过 App Store 分发，下载和更新由 Apple 按其隐私政策处理。如果你在 iPhone 或 iPad 的「设置 → 隐私与安全性 → 分析与改进」中打开了「与 App 开发者共享」，Apple 可能会把 Folio 的崩溃报告、诊断信息和汇总的使用统计（例如活跃设备数、使用次数、留存情况）提供给我们。你可以随时在同一位置关闭这个选项。

此外，无论是否打开这个选项，Apple 都会向开发者提供不指向具体个人的 App Store 汇总数据（例如下载量、国家或地区、设备类型）。你在 App Store 公开发表的评分和评论，我们也能看到，并可能公开回复。我们只用 Apple 提供的这些信息了解 App 的运行和使用情况、查找和修复问题、改进 Folio。

Apple 隐私政策：https://www.apple.com/legal/privacy/

邮箱服务商（腾讯 QQ 邮箱）：我们用 QQ 邮箱接收邮件，你发给我们的邮件会保存在腾讯的服务器上，由腾讯按其隐私政策处理。

腾讯隐私保护政策：https://privacy.qq.com/

我们选用的第三方服务（GitHub Pages、阿里云 OSS 和腾讯 QQ 邮箱）对收到的用户信息提供与本政策相同或不低于本政策的保护。除上述情况和法律法规要求的情形外，我们不会与任何第三方共享你的个人信息，也不会公开披露你的个人信息。

如果 Folio 将来转交给其他开发者运营，我们会在 App 内或本页面告知接收方的名称和联系方式，并要求对方继续按本政策处理你的信息；对方要改变处理目的或方式的，应当重新征得你的同意。

七、处理目的和依据

我们只为下面这些目的处理信息：

  • 设备上的信息：用来记住你的设置、收藏和消息，提供你正在使用的功能。它们只在你的设备上处理，不会发送给我们。
  • 你发来的邮件：用来处理问题、参考建议和回复你。依据是回应你主动提出的请求所必需。
  • 侵权投诉中的证明材料：用来核实投诉。依据是处理投诉、履行适用法律义务所必需。
  • 网页访问记录：由 GitHub 在提供网页时收到。依据是向你提供网页所必需。
  • 下载资源数据时的访问信息：由阿里云在提供这份公开文件时收到。下载资源数据是为了让你不用更新 App 就能看到新收录和修正后的资源，依据是向你提供 App 内容所必需。
  • Apple 提供的诊断和使用统计：用来了解 App 的运行和使用情况、查找和修复问题、改进 Folio。依据是你在 iOS 设置中作出的选择（同意），你可以随时关闭。

如果要把信息用于上面没有列出的目的，我们会先更新本政策；需要征得你同意的，会先征得你的同意。

八、网页版和公开网页

网页版和 App 的处理方式相同：设置、收藏和消息记录保存在浏览器为该网站域名提供的本地存储里，不会发送给我们。在浏览器设置中清除该网站的数据即可删除。

内容更新：Folio 的资源数据（资源名称、分类、导语、速览和学习指南等公开内容）放在阿里云对象存储（OSS）上的一个公开文件里。App 和网页版会在启动时、从后台回到前台时（距上次检查超过 30 分钟），以及你点「检查更新」或下拉刷新时下载这个文件；有新内容就直接显示，不用更新 App。这个请求只是下载这份公开文件，不带 Cookie，也不发送你的收藏、设置或任何其他个人信息；和访问普通网页一样，阿里云会收到 IP 地址等访问信息（见第六节）。最近一次下载的数据保存在设备上，没联网时继续使用。

本隐私政策和技术支持页面是静态网页，不使用 Cookie，不包含统计、广告或追踪代码，也不加载任何第三方网站的字体、脚本等资源。

九、App 不做的事

  • 不需要账号，不收集姓名、手机号等注册信息。
  • 不包含广告，也不包含统计分析、崩溃上报或其他追踪类第三方工具。
  • 不跨 App 或网站追踪你，不使用广告标识符（IDFA）。
  • 不出售或出租你的个人信息，不做用户画像，也不基于你的信息做自动化决策。
  • 不访问你的位置、相机、麦克风、通讯录、照片或文件。
  • 不发送推送通知；消息中心的内容都在你的设备上生成。
  • 不使用 Cookie，不读取剪贴板。

十、数据存放地点

我们（开发者）位于中国大陆，你发来的邮件主要由我们在中国大陆查看和处理。邮件保存在腾讯 QQ 邮箱的服务器上；GitHub 和 Apple 的服务器可能位于你所在国家或地区以外。

资源数据文件存放在阿里云位于中国香港的服务器上。App 和网页版下载它时，你的 IP 地址等访问信息会传到那里。

如果你从欧盟等地区给我们发邮件，邮件会被传输到中国大陆处理。中国大陆不在欧盟认定数据保护水平充分的国家或地区之列。

你设备上保存的信息留在你的设备上，除非你自己复制、分享或发送，或者它们随设备备份一起被备份（见第十一节）。

十一、保存期限与删除

设备上的信息会一直保存，直到你删除。消息中心最多保留最近 60 条消息，更早的会被自动删除；其中每日精选只保留最近 7 条。

反馈记录（包括你填写的联系方式）实际上会长期保留在设备上：每日精选不会把它挤出，只有之后又积累了 50 多条内容更新或反馈，它才会被自动删除。

App 内目前没有一键清除数据的按钮。你可以随时取消收藏或修改设置；要删除全部数据（包括反馈记录），iOS App 请删除 Folio App，网页版请在浏览器设置中清除该网站的数据。

在 iOS 上，这些数据可能会包含在你的 iCloud 或电脑备份中（取决于你的备份设置），从备份恢复设备时可能会一起恢复。设备存储空间不足时，系统也可能会清除这些数据。

使用网页版时，如果你较长时间没有访问该网站，部分浏览器可能会自动清除这些数据，例如 Safari 在你使用 Safari 的 7 天里都没有访问该网站时。

你发给我们的邮件，我们会保留到问题处理完毕、不再需要和你沟通为止，之后删除；侵权投诉的往来邮件和证明材料，保留到相关事项了结为止。除法律另有要求外，你可以随时要求我们提前删除。

GitHub、阿里云和 Apple 收到的信息，按它们各自的政策保存。

十二、你的权利

你对自己的个人信息享有查阅、复制、更正、补充、删除和撤回同意等权利。Folio 没有账号，大部分信息只在你的设备上，你可以直接管理：

  • 查阅：在「我的」里查看收藏和设置；在消息中心（顶部右侧的铃铛）查看反馈记录。
  • 复制：反馈记录可以在消息中心点「再次复制」；收藏目前不能一键导出，可以逐条查看或分享。
  • 更正：随时在 我的 → 设置 中修改语言、外观、视图密度等设置。
  • 删除：取消收藏，或按第十一节删除 App、清除网站数据。
  • 撤回同意：分享、复制和发送反馈都需要你每次主动操作，你可以随时停止使用这些功能；与开发者共享诊断和使用统计的选项，可以随时在 iOS 设置中关闭。
  • 注销账号：Folio 没有账号，不涉及注销。删除 App 即可清除 App 保存的全部数据。

我们看不到你设备上的数据，也无法确认你是谁，因此无法替你查阅或删除设备上的信息。

对于你通过邮件发给我们的信息，你可以发邮件到 1421718903@qq.com，要求查阅、复制、更正、补充或删除，或要求我们不再联系你。你也可以要求我们限制或停止处理这些信息、对本政策作出解释说明，或在符合法律规定的条件下把这些信息的副本转给你指定的其他处理者。

为确认是你本人，我们可能会请你用当初发信的邮箱联系我们。我们会在合理时间内处理并答复；如果不能满足你的请求，会说明理由。

如果你认为我们处理个人信息的方式不当，请先联系我们；你也有权向所在地的个人信息保护监管机构投诉。

十三、信息安全

App 不会把你的数据上传到我们的服务器。你设备上的数据受设备本身的安全措施保护，例如锁屏密码。对于你发给我们的邮件，我们会采取合理的措施防止未经授权的访问，但任何网络传输和存储方式都无法做到绝对安全。

如果发生涉及你个人信息的安全事件，我们会按照适用法律的要求，通过邮件等方式告知你。

十四、未成年人

Folio 是面向所有人的 3D 与 AI 动态和学习资源 App，不需要账号，也不会主动收集任何人的个人信息，包括未成年人。

如果你未满 18 周岁，请在父母或其他监护人的指导下阅读本政策。

如果你未满 14 周岁（或你所在地区法律规定的其他年龄），请在父母或其他监护人陪同下阅读本政策，并在取得他们同意后再给我们发邮件。

如果我们发现在未取得监护人同意的情况下收到了儿童的个人信息，会将其删除。监护人如有疑问，请联系 1421718903@qq.com。

十五、政策更新

App 的功能变化时，我们可能会更新本政策。更新后的版本会发布在本页面和 App 内，并修改顶部的日期。

如果变化涉及收集新的个人信息、改变使用目的或增加新的第三方服务，我们会在 App 内（例如消息中心）或本页面上明显提示；需要征得你同意的，会先征得你的同意。

十六、联系我们

对本政策有任何疑问、意见或请求，请发邮件到 1421718903@qq.com，或在 App 内 我的 → 帮助与支持 → 联系我们 找到联系方式。
